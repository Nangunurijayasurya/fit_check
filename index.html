Good to know

Frequently asked questions.

What is a Zepcha Fit Passport?

A reusable fit profile that helps translate body measurements into size guidance for participating fashion brands.

Do I need to enter measurements every time?

The goal is to create your profile once and reuse it across supported shopping experiences.

Will the recommended size always be perfect?

No tool can guarantee a perfect fit. Brand cuts, fabrics, garment types and personal preferences vary.

Is the demo login secure?

No. This page demonstrates a login interface only. A production application requires secure backend authentication.

Does the demo use real AI?

No. It uses simplified size thresholds to demonstrate the user experience. A real AI recommendation system needs a trained model and reliable product sizing data.
